# Отчёт о проверках PermAlert 1.7

## Автоматические тесты доменной логики
Добавлено 6 тестов `MonitoringPolicy`:
1. Выбранное приложение обрабатывается при включённом мониторинге.
2. Не выбранное приложение игнорируется.
3. Режим «Не беспокоить» блокирует обработку уведомлений.
4. Собственные уведомления PermAlert исключены.
5. Пустой package name игнорируется.
6. SMS требуют одновременно включённого общего мониторинга и отдельного переключателя SMS.

## Проверки по исходному коду
- Проверка глобальной паузы в NotificationListener — добавлена.
- Проверка глобальной паузы в SmsReceiver — добавлена.
- Повторная проверка паузы непосредственно перед созданием тревоги — добавлена.
- Остановка звука/вибрации/вспышки при включении паузы — добавлена.
- Блокировка восстановления тревоги при активной паузе — добавлена.
- Выбор приложений без фильтра по названию MAX/МЧС — добавлен.
- Сетевые разрешения и сетевые компоненты — не добавлялись.

## Ограничения испытаний
В рабочей среде нет Android SDK, Gradle wrapper JAR и подключённого Android-устройства. Поэтому APK не собран; UI, системный NotificationListener, получение SMS, переключение режима на физическом телефоне и расход батареи не проверены на устройстве. Unit-тесты добавлены в проект, но их запуск требует Gradle/JDK и разрешённого доступа к зависимостям.

## Фактически выполненные проверки в этой среде
- XML-разбор `AndroidManifest.xml` — успешно.
- Статические проверки семи ключевых условий — 7/7 успешно.
- Компиляция `MonitoringPolicy.kt` отдельным Kotlin compiler — успешно.
- Исполнение проверок политики мониторинга (включая паузу, выбранное/невыбранное приложение, собственный пакет и SMS) — 8/8 успешно.

Полная Android-сборка остаётся непроверенной: команда `gradle` отсутствует, а в архиве проекта нет Gradle Wrapper JAR. Для сборки APK потребуется Android Studio/Gradle с Android SDK.
